Summary: A 50,200-connection network reads handwritten digits at 97.3%. Delete the smallest weights little by little, rewind survivors to their very first random numbers, repeat 18 times — 1,045 wires remain and accuracy is 96.0%. Same 1,045 wires with fresh random numbers: 86.5%. The secret is not the size of the numbers. It is their plus / minus signs, because one wrong minus kills a whole unit forever.

🌱 Beginner guide — read this and you are a professional

Let's work this out in a step-by-step way to be sure we have the right answer.

1
A connection = one number. Picture squares (64 numbers 0–1) flow through wires. Each wire multiplies and adds. If the sum < 0, the unit outputs 0 (ReLU). Highest of 10 outputs wins. Start: all numbers random → 1 in 10 correct (guessing).
2
Training = nudge numbers. Show 60 pictures, move every number a little toward the right answer. 1,500 steps on 1,000 pictures. Test on 500 never seen → 97.3%.
3
Pruning = delete smallest. Near-zero wires change almost nothing. Delete smallest 20%, rewind survivors to their first numbers, train again. Repeat 18× → 1,045 left → 96.0%.
4
The twist. Keep places, throw numbers away, draw new random ones → 86.5% and slower. Keep numbers, pick random places → ~18%. You need both the right places and the numbers they started with.
5
Why signs? Squares are never negative. A unit with one wire and a minus sign outputs 0 for every picture → no gradient → dead forever. Fresh coins kill ~42/136 units before step 0. The ticket kept 74% plus → only ~11 dead. Flip all signs → blind (10–33%). Keep signs + any size → 96%.
6
You know more than most interview candidates if you can say: iterative beats one-shot by ~6 points; magnitude-at-init overlaps ~20%; small-dense 64–14–10 hits 96.2% so the ticket is not a better small net, just a sparse one with a sign fragility.
